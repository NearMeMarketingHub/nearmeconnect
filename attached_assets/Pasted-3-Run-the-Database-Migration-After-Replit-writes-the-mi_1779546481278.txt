🗂️ 6. Backfill Existing Task Data
After implementation, run these one-time cleanup queries:

sql

-- Populate assigned_to_name on all existing tasks that have it blank
UPDATE public.tasks t
SET assigned_to_name = u.first_name || ' ' || u.last_name
FROM public.users u
WHERE t.assigned_to = u.id
AND (t.assigned_to_name IS NULL OR t.assigned_to_name = '');

-- Confirm how many tasks got updated
SELECT COUNT(*) FROM public.tasks WHERE assigned_to_name IS NOT NULL;
Tell Replit to add this as a migration script too so it runs once on deploy.
