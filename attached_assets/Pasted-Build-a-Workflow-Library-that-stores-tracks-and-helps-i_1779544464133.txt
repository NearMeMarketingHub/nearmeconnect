=== WORKFLOW LIBRARY UI ===

Admin view (/admin/workflow-library):
  Filter by: Category | Hub Required | Complexity | Status
  Search by name
  Each workflow card shows:
    Name, category badge, hub badge, trigger description,
    business impact, complexity indicator (Easy/Medium/Advanced)
    "Assign to Client" button → opens company multi-select
    Assigns to company_workflows with status = 'planned'

Per-company view (/company/:companyId/workflows):
  Tab 1: Recommended — workflows not yet assigned, sorted by business impact
  Tab 2: In Progress — company_workflows WHERE status = 'planned' or 'building'
  Tab 3: Active — company_workflows WHERE status = 'active'
  
  Each workflow row shows:
    Name | Status badge | HubSpot Workflow ID (if linked) | 
    "Mark Active" button | "View in HubSpot" button | Notes

  "Activate" changes status to 'active' + saves hubspot_workflow_id if provided
  "Add Note" → saves to company_workflows.notes
  
  Progress bar: X of 100 workflows active for this client
