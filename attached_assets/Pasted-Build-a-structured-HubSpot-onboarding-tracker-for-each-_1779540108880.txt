Build a structured HubSpot onboarding tracker for each client company.
Reads/writes to hubspot_onboarding_checklist table.
Accessible at: /company/:companyId/hubspot-onboarding

=== UI LAYOUT ===

Page header: Company name + "HubSpot Onboarding" + overall progress ring 
  (X of Y items complete, shown as a circular progress indicator)

Progress bar row showing % complete per section:
  Universal: [████░░░░] 40% (8/20)
  CRM: [██░░░░░░] 20% (3/15)
  etc.

Each section is a collapsible accordion:
  Section header: name + X/Y complete + section progress bar
  Inside: list of checklist items as rows:
    [ ] checkbox | item label | description (hover tooltip) | 
    assigned to (optional) | notes | completed by/date (if done)
  
  Checking a box:
    UPDATE hubspot_onboarding_checklist SET 
      is_completed = true, 
      completed_by = currentUserId,
      completed_by_name = currentUserName,
      completed_at = now()
    Also creates a notification to account manager if a full section completes.
  
  Unchecking a box: clears completed_by, completed_by_name, completed_at

Add Notes button per item → inline text area saves to checklist.notes

"Assign to team member" per item → saves to company_knowledge_items or a 
  task linked to that checklist item

=== HUBSPOT LAUNCH READINESS REPORT ===
"Generate Report" button → creates a formatted summary showing:
  - Completed items: green list
  - Remaining items: red list grouped by section
  - Estimated time to complete
  - "Ready to Launch" / "Not Ready" status per Hub
