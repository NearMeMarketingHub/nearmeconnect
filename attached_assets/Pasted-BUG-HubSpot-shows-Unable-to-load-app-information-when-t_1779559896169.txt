STEP 3: Verify the HubSpot Developer App settings match EXACTLY.
  The user must check app.hubspot.com/developer → their app → Auth tab:
  
  Required redirect URL must be EXACTLY:
    https://portal.nearmemarketinghub.com/api/hubspot/callback
  
  Common mistakes that cause "Unable to load app information":
    ✗ Trailing slash: .../callback/  (remove it)
    ✗ HTTP instead of HTTPS: http://portal...
    ✗ Wrong path: /api/hubspot/oauth/callback vs /api/hubspot/callback
    ✗ App is in "draft" state and not published in HubSpot developer portal
    ✗ Wrong scopes — some scopes require the app to be a "public app" type
    ✗ Client ID copied with extra spaces
